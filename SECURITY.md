# Segurança

Este projeto é uma demonstração e roda contra o sandbox do Asaas com dados fictícios. Não use com dados reais de clientes.

Para relatar uma vulnerabilidade, abra um [aviso privado de segurança](https://github.com/rafaelgoncalvesml/boletos-em-lote/security/advisories/new) no GitHub. Não publique o problema em uma issue aberta.

O CI roda `gitleaks` no histórico inteiro e `pip-audit` nas dependências a cada push.
